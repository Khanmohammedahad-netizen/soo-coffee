# Soo Coffee Website

A premium, luxury warm-minimal website for Soo Coffee — a specialty coffee shop and pickleball court in Jubilee Hills, Hyderabad.

## Tech Stack
- **Framework**: Vite (Vanilla JS)
- **Styling**: Vanilla CSS
- **Animations**: GSAP (ScrollTrigger), AOS
- **Smooth Scroll**: Lenis

## Key Features
- **Luxury Aesthetic**: Deep espresso and warm copper color palette.
- **Interactive Experience**: GSAP ScrollTrigger for text reveals and parallax effects.
- **Dynamic Stats**: Animated counters for reviews and court counts.
- **Responsive Design**: Optimized for mobile and desktop.
- **Custom Assets**: AI-generated premium imagery for hero and pickleball sections.

## Getting Started
1. Clone the repository.
2. Run `npm install`.
3. Run `npm run dev` to start the local development server.
